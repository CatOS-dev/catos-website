# 认识 CatOS

CatOS 是一个面向桌面使用的 Arch Linux 发行版。它不试图隐藏 Arch 的生态，而是把安装、桌面预设、软件仓库、启动和系统恢复整理成能够协同工作的默认方案。

## CatOS 解决什么问题

直接安装 Arch Linux 可以获得高度自由的系统，但从安装介质到稳定的日常桌面仍然需要完成许多选择：磁盘布局、启动器、桌面环境、输入法、镜像源、显卡驱动、快照策略和常用工具。

CatOS 的目标是让这些选择拥有一个经过测试的默认答案，同时继续允许用户替换组件或深入调整系统。

## 当前系统路线

CatOS 围绕以下部分进行集成：

- 使用定制的 Calamares 完成安装和组件选择；
- 使用 Btrfs 作为主要文件系统方案；
- 使用 Snapper 管理系统快照；
- 通过 Limine 及配套工具发现可启动的内核和快照；
- 通过 CatOS 软件仓库交付发行版集成包、主题和工具；
- 提供多种经过整理的桌面环境预设。

## 设计原则

### 默认配置需要能够一起工作

单独可用的组件不等于完整系统。安装器、启动器、快照工具和软件包需要共享一致的目录、生命周期和错误处理约定。

### 恢复能力是交付的一部分

快照不能只是在磁盘上存在。它还需要在更新后保持资源一致，并能从启动环境被发现、解释和选择。

### 不替用户制造不可见的魔法

CatOS 会提供自动化，但关键状态应该可以检查。配置、构建来源、快照关系和启动条目应尽量保持可诊断。
