# 简介

:::note 旧站内容

以下介绍来自旧版 CatOS 网站，在新的发行版介绍完成前暂时保留。涉及默认桌面和具体组件的内容可能与当前开发版本不同。

:::

CatOS是一个**开源的、基于 Arch Linux的、开箱即用**的Linux发行版，旨在提供出色的操作系统用户体验。

Arch是一个优秀的Linux发行版，快速、稳定、安全，即使是在老旧的计算机上也能有非常出色的体验。但是纯指令式的安装过程较为复杂，需要有较高的计算机基础，您需要为此付出足够的时间、精力和耐心。即使顺利安装完成，您还将面临安装图形界面、配置软件源、安装输入法、安装显卡驱动、安装AUR助手等一系列配置过程。

并不是每个人都有足够的时间、精力和耐心完成这一切，很多新手可能会被这一艰巨的过程阻挡在Arch世界的大门之外。这正是CatOS诞生的理由：在继承Arch优点的同时，使其安装简便、开箱即用、更加用户友好。无需复杂的安装和配置，您就可以领略到Arch的魅力。

同时，旧版CatOS在Arch Linux上精心打磨，采用KDE Plasma作为默认桌面环境，并对其进行定制修改，以期为用户提供更好的使用体验。
