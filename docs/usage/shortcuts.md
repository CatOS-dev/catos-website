# 快捷键

快捷键取决于安装时选择的桌面环境。下面的表格主要对应 CatOS KDE Plasma 预设，GNOME、Xfce、Niri、Sway 等环境可能使用不同组合。

`Super` 通常指带 Windows 标志的按键。

| 操作 | KDE Plasma 预设 |
| --- | --- |
| 打开任务管理器 | `Super` + `Esc` |
| 打开文件管理器 | `Super` + `E` |
| 锁屏 | `Super` + `L` |
| 显示桌面 | `Super` + `D` |
| 打开启动器 / 搜索 | `Alt` + `Space` |
| 显示剪贴板 | `Super` + `V` |
| 截图 | `Print` / `PrtSc` |
| 切换任务 | `Alt` + `Tab` |
| 打开终端 | `Ctrl` + `Alt` + `T` |
| 放大视图 | `Super` + `=` |
| 缩小视图 | `Super` + `-` |
| 打开表情选择器 | `Super` + `.` |

![快捷键设置](/img/docs/shortcut.png)

在 KDE Plasma 中，可前往：

```text
系统设置 → 键盘 → 快捷键
```

其他桌面的配置入口和默认组合见各桌面上游文档。CatOS 提供的桌面选项见[桌面环境与窗口管理器](../desktops.md)。

输入法快捷键单独由 Fcitx5 管理，见[使用和排查 Fcitx5](./input-method.md)。
