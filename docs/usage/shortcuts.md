# 快捷键

旧版CatOS预置了常用快捷键，大部分操作与Windows习惯相近。`Super`通常指带有Windows徽标的按键。

| 操作 | 快捷键 |
| --- | --- |
| 打开任务管理器 | `Super` + `Esc` |
| 打开文件管理器 | `Super` + `E` |
| 锁屏 | `Super` + `L` |
| 显示桌面 | `Super` + `D` |
| 打开启动器 | `Alt` + `Space` |
| 显示剪贴板 | `Super` + `V` |
| 截图 | `Print` / `PrtSc` 或 `F2` |
| 切换任务 | `Alt` + `Tab` |
| 打开活动列表 | `Super` + `Q` |
| 打开终端 | `Ctrl` + `Alt` + `T` |
| 放大视图 | `Super` + `=` |
| 缩小视图 | `Super` + `-` |
| 打开表情选择器 | `Super` + `.` |

![旧版快捷键设置](/img/docs/shortcut.png)

也可以在“系统设置 → 输入和输出 → 键盘 → 快捷键”中自定义快捷键。
