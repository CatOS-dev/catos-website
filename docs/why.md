# 为什么选择CatOS

:::note 旧站内容

以下内容来自旧版网站。GRUB、Timeshift、软件源和Linux子系统等具体实现尚未按当前版本修订。

:::

## 📤 开箱即用

一旦系统安装完成，即是原生中文、开箱即用的状态。旧版系统已经配置好图形桌面环境、国内镜像源（包括archlinuxcn和arch4edu源）、AUR助手（yay）、中文输入法、GRUB主题、显卡驱动（包含N卡闭源驱动）等，更加符合国内用户的使用环境。

## 💻 安装简便

CatOS使用定制版的Calamares图形化安装程序，就算是没有经验的新手也可以通过图形界面完成安装。

旧版安装介质支持离线安装和在线安装两种模式。离线安装完成后与LiveCD环境相同，全程无需联网；在线安装允许用户选择桌面环境和其他软件包，用于定制自己的Linux系统。

## 😊 用户友好

CatOS旨在提供出色的操作系统用户体验。我们相信，不管用户的技术背景如何，都应该能够轻松上手和使用CatOS。

## 🏵️ 生态丰富

CatOS继承Arch Linux的软件生态，旧版系统内置archlinuxcn和AUR支持，并通过软件助手提供微信、QQ等常用软件的安装入口。

## 🚀 快速稳定

得益于Arch Linux的特性，CatOS力求成为一个轻量、快速、稳定的系统。旧版系统默认使用Btrfs文件系统，并配合Timeshift提供系统快照。

## 🐱 Linux子系统

旧版CatOS支持包括Ubuntu、CentOS、Red Hat、openSUSE、Deepin、Void等在内的多种Linux子系统，并提供一键安装入口，可用于体验其他发行版或创建隔离的开发、测试环境。
