# 安装概览

CatOS 使用定制的 Calamares 图形安装器。安装器不仅复制系统文件，还需要根据选择组合桌面环境、启动方案、磁盘布局和软件包。

## 安装前准备

1. 备份目标磁盘上的重要数据；
2. 验证下载镜像的校验值与签名；
3. 确认固件启动模式和目标磁盘；
4. 有条件时使用有线网络完成首次安装与更新；
5. 对双系统设备，提前确认 EFI 系统分区和现有启动方式。

## 安装器中的主要步骤

### 地区和键盘

选择语言、时区和键盘布局。中文安装不强制系统只能使用中文，之后仍可添加其他 locale。

### 桌面环境

桌面预设是一组经过整理的软件包和配置，不只是安装一个桌面元包。不要同时选择会产生文件冲突的预设。

### 磁盘布局

自动分区适合清空整块目标磁盘。手动分区适合双系统、自定义子卷或已有 EFI 系统分区的设备。

### 启动方案

启动器必须与固件模式和磁盘布局匹配。安装器会限制明显不适用的选项，但用户仍应确认最终选择。

## 首次启动后

完成安装并重启后，建议依次检查：

```bash
uname -a
findmnt /
snapper list
```

随后进行完整系统更新，并确认新的内核、启动条目和快照状态彼此一致。

## 遇到问题时

保留安装器日志、分区布局和启动模式信息。只描述“无法启动”通常不足以判断问题发生在固件、启动器、内核还是根文件系统。
