# 安装 CatOS

CatOS 2026.07.19 提供**离线安装**和**在线安装**两种方式。两者都使用 Calamares 图形安装器，但系统来源、可选项目和驱动配置流程不同。

## 选择安装方式

| 项目 | 离线安装 | 在线安装 |
| --- | --- | --- |
| 网络要求 | 不需要联网 | 需要稳定网络 |
| 系统来源 | 将 Live 系统复制到硬盘 | 从软件仓库安装目标系统 |
| 桌面环境 | 使用镜像内置桌面 | 可选择桌面、窗口管理器或无桌面系统 |
| 软件选择 | 使用镜像内置软件集合 | 可选择输入法、Shell、额外内核、虚拟化、容器和常用软件 |
| 软件仓库 | 使用镜像内置配置 | 可选择 CatOS 或 CatOS + CachyOS 仓库 |
| 启动方式 | 使用离线安装默认方案 | 可选择 GRUB、Limine、systemd-boot、UKI 或 EFI Stub |
| 驱动处理 | 继承镜像驱动并清理不需要的组件 | 在目标系统中运行 `chwd --autoconfigure` |
| 安装速度 | 较快且不受网络影响 | 取决于网络和仓库速度 |
| 适合用户 | 希望快速安装默认 CatOS | 希望从安装阶段定制系统 |

### 选择离线安装

离线安装适合：

- 网络不可用或不稳定；
- 希望快速获得与 Live 环境接近的默认系统；
- 不需要在安装阶段更换桌面、仓库或启动方案；
- 希望先完成安装，再进入系统进行更新和调整。

继续阅读：[离线安装](./offline-installation.md)。

### 选择在线安装

在线安装适合：

- 希望选择桌面环境或窗口管理器；
- 希望安装无图形界面的基础系统；
- 需要选择启动方式、软件仓库、额外内核和附加软件；
- 希望由 chwd 根据目标硬件自动配置驱动。

继续阅读：[在线安装](./online-installation.md)。

## 安装前必须确认

1. 从[下载页面](/docs/download)选择适合显卡的镜像，并核对 SHA-256；
2. 备份目标磁盘中的重要数据；
3. 确认设备使用 UEFI 还是传统 BIOS；
4. 双系统用户确认现有 EFI 系统分区和 Windows 恢复密钥；
5. 在线安装用户准备可靠网络；
6. 希望使用可启动快照时，应选择 Btrfs，并选择支持快照集成的启动器。
