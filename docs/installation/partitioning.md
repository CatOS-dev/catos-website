# 磁盘分区与文件系统

分区决定系统数据放在哪里，也会限制可用的启动方式、加密、休眠和快照功能。任何分区操作前都应备份重要数据。

## 分区表

| 使用环境 | 建议分区表 | 说明 |
| --- | --- | --- |
| UEFI 新设备 | GPT | 当前主流方案，支持所有 CatOS UEFI 启动方式 |
| Windows 10/11 双系统 | GPT | 应与现有 Windows 保持相同固件模式 |
| 传统 BIOS | MBR 或 GPT | 只能选择 GRUB；GPT 可能需要 BIOS Boot 分区 |
| Limine | GPT | CatOS 当前配置要求 UEFI + GPT |
| systemd-boot | GPT | 仅 UEFI |
| UKI | GPT | 仅 UEFI |
| EFI Stub | GPT | 仅 UEFI |

:::warning 不要混用启动模式

如果 Windows 以 UEFI 模式安装，CatOS 也应从 UEFI 启动项进入安装介质并以 UEFI 方式安装。不要在同一台双系统设备上混用传统 BIOS 和 UEFI。

:::

## 自动分区方式

Calamares 根据磁盘状态可能提供以下方式：

### 抹除磁盘

清空目标磁盘并自动建立 CatOS 所需分区。适合：

- 整块磁盘只安装 CatOS；
- 不需要保留原有数据；
- 不熟悉手动分区。

这是最简单的方式，也是破坏性最大的方式。

### 安装到现有系统旁边

缩小已有分区，为 CatOS 分配空间。适合简单双系统，但在磁盘空间不足、已有分区复杂或 BitLocker 启用时应先在原系统中整理磁盘。

### 替换一个分区

只格式化选中的分区并安装 CatOS，其他分区保持不变。必须确认所选分区没有需要保留的数据。

### 手动分区

适合：

- 双系统；
- 复用已有 EFI 系统分区；
- 自定义 `/home`、数据分区或加密；
- 已有复杂分区布局。

## 手动分区最低要求

### UEFI 系统

至少需要：

1. 一个 EFI 系统分区（ESP）：FAT32，挂载到 `/boot/efi`；
2. 一个根分区：挂载到 `/`；
3. 可选 Swap 分区或 Swap 文件。

双系统通常可以复用 Windows 已有 ESP。复用时一般**不要格式化**，只设置正确挂载点。

### 传统 BIOS 系统

需要根分区；使用 GPT 和 GRUB 时还可能需要一个无文件系统、带 `bios_grub` 标志的小型 BIOS Boot 分区。

## EFI 系统分区大小

| 启动方式 | 最低值 | 建议值 |
| --- | ---: | ---: |
| GRUB | 300 MiB | 300 MiB 或更大 |
| Limine | 1 GiB | 2 GiB |
| systemd-boot | 1 GiB | 2 GiB |
| UKI | 1 GiB | 2 GiB |
| EFI Stub | 1 GiB | 2 GiB |

GRUB 主要将自身放在 ESP，而其他方案可能把内核、initramfs 或 UKI 放入 ESP，因此需要更多空间。双系统复用较小 ESP 时，应检查剩余空间。

## 文件系统选择

安装器当前提供：

- Btrfs；
- ext4；
- ext3；
- JFS；
- XFS；
- F2FS。

### Btrfs：CatOS 默认

推荐大多数用户使用。优势包括：

- 支持子卷；
- 支持 Snapper 快照；
- 支持与 GRUB、Limine、systemd-boot 的可启动快照集成；
- 适合滚动发行版更新前的系统保护。

快照不是备份，不能防止磁盘损坏或整盘误操作。

### ext4：简单和兼容

适合不需要 Btrfs 快照、希望使用传统文件系统的用户。ext4 不能使用 CatOS 的 Btrfs 启动快照功能。

### XFS

适合了解其管理和缩容限制的高级用户。不能使用 Btrfs 快照集成。

### F2FS

主要用于特定闪存设备场景。普通 NVMe 或 SATA SSD 不需要仅因“闪存”而选择 F2FS。

### ext3 和 JFS

保留用于兼容和特定需求，不建议新的普通桌面安装选择。

## 是否单独划分 `/home`

单独 `/home` 不是必需项。

优点：

- 重装根系统时可以单独保留用户数据；
- 可以独立分配容量和文件系统。

注意：

- 用户配置也可能导致新系统出现兼容问题；
- 单独分区无法替代备份；
- 容量分配错误后调整更麻烦。

对于普通单系统安装，使用 Btrfs 子卷通常比单独建立 `/home` 分区更灵活。

## Swap 选择

当前安装器提供：

| 选项 | 适用情况 |
| --- | --- |
| 不创建 Swap | 内存充足且明确不需要休眠；仍可能在高内存压力下直接触发 OOM |
| 小型 Swap 分区 | 普通桌面使用，限制最大磁盘占用 |
| 支持休眠的 Swap | 需要休眠，容量至少接近物理内存 |
| Swap 文件 | 布局灵活，适合普通桌面；Btrfs 上由安装器处理所需配置 |

内存较少的设备不建议完全关闭 Swap。需要休眠时，应选择支持休眠的容量，并在安装后测试恢复是否正常。

## 加密

如果启用磁盘加密：

- 保存好解密密码；
- 确认启动器支持当前布局；
- 备份 LUKS 头和重要数据；
- 注意未加密 ESP 仍会保存启动文件。

安装摘要中应再次核对加密范围和将被格式化的分区。
