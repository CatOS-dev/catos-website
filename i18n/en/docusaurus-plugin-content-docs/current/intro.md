# About CatOS

CatOS is an Arch Linux distribution for desktop use. It keeps the Arch ecosystem visible while providing a coherent default for installation, desktop presets, package delivery, boot management, and system recovery.

## What CatOS integrates

- A customized Calamares installation flow;
- Btrfs as the primary filesystem option;
- Snapper for snapshot management;
- Limine and companion tools for bootable kernels and snapshots;
- A CatOS repository for distribution integration packages;
- Curated presets for multiple desktop environments.
