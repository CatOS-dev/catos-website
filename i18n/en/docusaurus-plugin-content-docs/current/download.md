# Download CatOS

Official images will be published through channels announced by the CatOS-dev organization. The new release workflow is still being organized, so this page does not invent a version number or download link.

Follow the [CatOS-dev GitHub organization](https://github.com/CatOS-dev) and the [project news](/en/news) for release updates.

A release page will include the ISO, SHA-256 checksum, signature, release notes, known issues, and hardware requirements.
