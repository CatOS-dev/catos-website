# Why CatOS

:::note Legacy website content

The following content comes from the previous website. Details such as GRUB, Timeshift, repositories, and Linux subsystems have not yet been revised for the current version.

:::

## 📤 Out-of-the-box

Once the system is installed, everything is ready, including a designed desktop environment, software repositories such as archlinuxcn and arch4edu, an AUR helper, input methods, a GRUB theme, NVIDIA drivers, and more.

## 💻 Easy to install

CatOS uses a customized version of the Calamares graphical installer, making installation available even to inexperienced users. The previous installer offered offline and online installation modes.

## 😊 Usability

CatOS is designed to be user-friendly. We believe that anyone, regardless of technical background, should be able to use and benefit from CatOS.

## 🏵️ Rich software ecosystem

CatOS inherits Arch Linux's software ecosystem. The previous release included ArchLinuxCN and AUR support, together with a software assistant for commonly used applications.

## 🚀 Speed and reliability

Thanks to the characteristics of Arch Linux, CatOS aims to be a lightweight, fast, and stable system. The previous release used Btrfs together with Timeshift snapshots.

## 🐱 Linux subsystem

The previous CatOS release supported multiple Linux subsystems, including Ubuntu, CentOS, Red Hat, openSUSE, Deepin, and Void, with one-click installation entries.
