# Keyboard shortcuts

Shortcuts depend on the selected desktop environment. The table below mainly describes the CatOS KDE Plasma preset.

| Action | KDE Plasma preset |
| --- | --- |
| Task manager | `Super` + `Esc` |
| File manager | `Super` + `E` |
| Lock screen | `Super` + `L` |
| Show desktop | `Super` + `D` |
| Launcher or search | `Alt` + `Space` |
| Clipboard | `Super` + `V` |
| Screenshot | `Print` |
| Switch tasks | `Alt` + `Tab` |
| Terminal | `Ctrl` + `Alt` + `T` |
| Zoom in / out | `Super` + `=` / `Super` + `-` |
| Emoji selector | `Super` + `.` |

![Shortcut settings](/img/docs/shortcut.png)

In Plasma, edit shortcuts under System Settings → Keyboard → Shortcuts. CatOS defaults for Niri + DMS and Niri + Noctalia are included directly in [Desktop environments and window managers](../desktops.md). Other desktops have different upstream defaults.

Fcitx shortcuts are documented separately in [Using and troubleshooting Fcitx5](./input-method.md).
